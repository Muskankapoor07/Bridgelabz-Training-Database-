# Database JDBC Projects

Welcome to my **Database JDBC Projects** repository.

This repository contains Java-based database applications developed during my **BridgeLabz Backend Training Program**. The projects demonstrate database connectivity using **JDBC**, **PostgreSQL**, **Maven**, and Java while following clean coding practices and layered architecture.

---

# Repository Overview

This repository includes multiple JDBC-based applications that cover CRUD operations, database management, and Java backend development concepts.

---

# Projects

## 📌 Employee Payroll Application

A Java console application that manages employee payroll information using JDBC and PostgreSQL.

### Features
- Add Employee
- Update Employee Details
- Delete Employee
- Search Employee
- View Employee Records
- JDBC Database Connectivity

---

## 📌 Employee Payroll Application (Maven)

A Maven-based version of the Employee Payroll Application demonstrating dependency management and project organization.

### Features
- Maven Project Structure
- PostgreSQL Integration
- JDBC Connectivity
- CRUD Operations
- Layered Architecture

---

## 📌 Greeting JDBC Application

A Java application that stores and retrieves personalized greetings from a PostgreSQL database using JDBC.

### Features
- Add Greetings
- View Greetings
- Database Connectivity
- Prepared Statements
- Exception Handling

---

## 📌 Greeting JDBC Template Application

A Spring JDBC Template-based application that simplifies database operations using Spring Framework.

### Features
- Spring JDBC Template
- CRUD Operations
- Dependency Injection
- PostgreSQL Integration
- Clean Repository Layer

---

## 📌 LMS Project

A Library Management System developed using Java and JDBC for managing books and users.

### Features
- Book Management
- User Management
- Issue & Return Books
- JDBC Connectivity
- PostgreSQL Database
- CRUD Operations

# Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/Muskankapoor07/Bridgelabz-Training-Database-.git
```

## 2. Open the Project

Import the project into **IntelliJ IDEA** or your preferred Java IDE.

## 3. Configure PostgreSQL

- Install PostgreSQL.
- Create the required databases.
- Execute the SQL scripts provided in each project.
- Update the database URL, username, and password in the source code.

## 4. Run the Application

Compile and execute the desired project from your IDE or terminal.
